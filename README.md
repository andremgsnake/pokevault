# PokéVault
Collezione Pokémon, import CSV PriceCharting, listini ufficiali Cardmarket aggiornati via GitHub Actions alle 06:20 UTC ogni giorno.

## Abilitazione sito
GitHub → Settings → Pages → Build and deployment → Source: **GitHub Actions**.
Poi Actions → PokéVault - prezzi Cardmarket → Run workflow.

Il sito è https://andremgsnake.github.io/pokevault/
Le carte sono conservate **solo nel browser** (localStorage): esporta un CSV come backup. Non caricare mai la tua collezione nel repository. Le medie Cardmarket non sostituiscono il prezzo di mercato esatto per condizione/lingua.
